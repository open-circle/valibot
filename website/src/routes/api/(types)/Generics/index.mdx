# Generics

Extensible registry for generic type constructors.

## Generics

- `T` <Property {...properties.T} />
- `TArgs` <Property {...properties.TArgs} />

## Definition

- `Generics` <Property {...properties.Generics} />

The interface has no entries by default. Each registration describes how to extract and apply the arguments of a generic constructor.

| Property    | Purpose                                                                                |
| ----------- | -------------------------------------------------------------------------------------- |
| `getArgs`   | Extracts the arguments of `T` as a tuple. Returns `never` for types that do not match. |
| `applyArgs` | Reconstructs the generic from the resolved arguments in `TArgs`.                       |
