# summarize

Summarize the error messages of issues in a pretty-printable multi-line string.

```ts
const errors = v.summarize(issues);
```

## Parameters

- `issues` <Property {...properties.issues} />

### Explanation

If an issue in `issues` contains a path that can be converted to a dot path, the dot path will be displayed in the `errors` output just below the issue's error message.

If an issue contains sub issues with a path, such as the nested issues of the object options of a <Link href="../union/">`union`</Link> schema, they are displayed indented below the issue's error message. The dot path of each sub issue includes the path of its parent issue. Sub issues without a path are skipped, as the parent issue's error message already covers them, but their own sub issues with a path, such as those of a nested union, are still displayed.

## Returns

- `errors` <Property {...properties.errors} />

## Examples

The following example show how `summarize` can be used.

```ts
const Schema = v.object({
  nested: v.object({
    foo: v.string('Value of "nested.foo" is invalid.'),
  }),
});

const result = v.safeParse(Schema, { nested: { foo: null } });

if (result.issues) {
  console.log(v.summarize(result.issues));
}
```
