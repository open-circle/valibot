# mutualRecursiveAsync

Creates a map of mutually recursive async schemas.

```ts
const Schemas = v.mutualRecursiveAsync<TEntries>(build);
```

## Generics

- `TEntries` <Property {...properties.TEntries} />

## Parameters

- `build` <Property {...properties.build} />

### Explanation

The `build` callback receives a `ref` function. Call `ref` with the key of another entry to reference that entry inside the returned object. Valibot infers the recursive input and output types of each entry from this object.

> If a name does not match an entry, TypeScript reports an error. At runtime, Valibot throws an error for the same case.

## Returns

- `Schemas` <Property {...properties.Schemas} />

## Examples

The following examples show how `mutualRecursiveAsync` can be used.

### Category and product schemas

Schemas that reference each other.

```ts
const { category, product } = v.mutualRecursiveAsync((ref) => ({
  category: v.objectAsync({
    name: v.string(),
    products: v.arrayAsync(ref('product')),
  }),
  product: v.objectAsync({
    name: v.string(),
    category: v.optionalAsync(ref('category')),
  }),
}));
```

## Unrecognised Generics

When your recursive root is a type parameter of an unrecognised generic, the generic can vanish and be replaced with a strange object in the output type.

For example, this transform puts recursive children into an unregistered `WeakMap`:

```ts
const Schemas = v.mutualRecursiveAsync((ref) => ({
  node: v.pipeAsync(
    v.objectAsync({ name: v.string(), children: v.arrayAsync(ref('node')) }),
    v.transform((node) => ({
      name: node.name,
      children: new WeakMap(node.children.map((child) => [child, child])),
    }))
  ),
}));

type Output = v.InferOutput<typeof Schemas.node>;
```

The expected `Output` type is:

```ts
interface Node {
  name: string;
  children: WeakMap<Node, Node>;
}
```

But the actual `Output['children']` type comes out as:

```ts
{
  delete: (key: any) => boolean;
  get: (key: any) => any | undefined;
  has: (key: any) => boolean;
  set: (key: any, value: any) => any;
  readonly [Symbol.toStringTag]: string;
}
```

The fix is to extend `Generics` as explained on the <Link href="/api/Generics/">Generics</Link> page.
