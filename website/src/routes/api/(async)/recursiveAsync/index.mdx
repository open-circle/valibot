# recursiveAsync

Creates a recursive schema.

```ts
const Schema = v.recursiveAsync<TWrapped>(definition);
```

## Generics

- `TWrapped` <Property {...properties.TWrapped} />

## Parameters

- `definition` <Property {...properties.definition} />

### Explanation

The `definition` callback receives a `self` reference for use inside the returned schema. Valibot infers recursive input and output types from this definition.

The callback returns a schema directly, not a promise. The returned schema can perform asynchronous validation.

> When you nest `self`, use async-compatible schemas such as <Link href="/api/objectAsync/">`objectAsync`</Link> and <Link href="/api/arrayAsync/">`arrayAsync`</Link>.

## Returns

- `Schema` <Property {...properties.Schema} />

## Examples

The following examples show how `recursiveAsync` can be used.

### Category schema

Recursive schema to validate nested categories asynchronously.

```ts
const CategorySchema = v.recursiveAsync((self) =>
  v.objectAsync({
    name: v.string(),
    subcategories: v.arrayAsync(self),
  })
);
```
